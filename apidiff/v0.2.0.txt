# Reviewed incompatible API changes relative to v0.2.0.
#
# One entry per line: <package>: <exact apidiff change>.
# This file records the approved v0.3.0 migrations. The accompanying review
# material is the "Migrating accessor ownership from v0.2.0" section in
# docs/api-guide.md (#121), the guide's "Options" section, and the v0.3.0
# changelog's option-constructor and add-columns migration entries (#103):
# - Close() now returns error and implements io.Closer, and file.StorageOptions
#   is now an alias for lance.StorageOptionsAccessor, so the constructors and
#   the reader/writer/session option fields use the root accessor type.
# - OpenOption, WriteOption, CommitOption, BranchOption and TransactionOption
#   are interfaces, shared constructors return concrete option values, and the
#   add-columns methods take AddColumnsOption.
#
# This file belongs to an approved minor release only. A patch line must not
# add one. It stops applying when a new stable tag becomes the comparison base.
